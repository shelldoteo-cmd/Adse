# 사주풀이 사이트 데모

간단한 입력(이름, 생년월일, 출생 시간, 성별)을 받아 **연주(년주)** 와 **핵심 오행**을 계산하고,
데모용 해석 문구를 보여주는 정적 웹 페이지입니다.

## 실행 방법

브라우저에서 `index.html`을 직접 열거나, 아래처럼 로컬 서버를 실행하세요.

```bash
python3 -m http.server 8000
```

이후 `http://localhost:8000` 접속.

## 구성 파일

- `index.html` : 입력 폼과 결과 영역
- `styles.css` : 기본 UI 스타일
- `script.js` : 간단한 사주 계산/결과 렌더링 로직

## 참고

현재 로직은 실제 명리학 계산이 아닌 **MVP 데모용 간이 로직**입니다.
